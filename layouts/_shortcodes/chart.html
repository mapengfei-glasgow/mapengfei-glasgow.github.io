{{- /* chart: draw an interactive Chart.js figure from CSV data written directly in the page body. Chart.js is self-hosted (static/js/chart.umd.min.js, no CDN) and both the script and the stylesheet are only loaded on pages that actually use this shortcode. Usage — the first line is the header (first name = x, the rest = series names), every following line is one sample; empty cells become gaps: {{< chart xlabel="t (s)" ylabel="p (mmHg)" caption="Figure 12. ..." >}} t, inlet, outlet 0.000, 14.35, 85.0 0.005, 14.59, 85.1 {{< /chart >}} Parameters (all optional): type line (default) | bar | scatter xlabel x-axis title ylabel y-axis title title title drawn inside the canvas caption caption under the figure (academic pages style it like tables) height canvas height in px (default 320) legend true | false (default: shown when there is more than one series) xlog true for a logarithmic x axis ylog true for a logarithmic y axis (non-positive samples are dropped) xkind numeric (default) | category (category keeps the first column as labels) colors comma-separated colour overrides, one per series smooth true for a slightly smoothed line (default false) ymirror true to place a second series on a right-hand axis (comma-separated 1-based series indices, e.g. ymirror="2") The data itself remains part of the Markdown source, so a figure can be regenerated by editing numbers in the text — no image to re-upload. */ -}} {{- $id := printf "chart-%d" .Ordinal -}} {{- $height := .Get "height" | default "320" -}} {{- $type := .Get "type" | default "line" -}} {{- /* Split the inner CSV into a JSON array of rows; blank lines are ignored, so the data block can be indented or padded freely. The rows are assembled as JSON literals because collections.Append flattens slice arguments, which would turn the rows into one flat list of cells. */ -}} {{- $rows := slice -}} {{- range (split (trim .Inner "\n\r\t ") "\n") -}} {{- $line := trim . " \t\r" -}} {{- if $line -}} {{- $cells := slice -}} {{- range (split $line ",") -}} {{- $cells = $cells | append (printf "%q" (trim . " \t\r")) -}} {{- end -}} {{- $rows = $rows | append (printf "[%s]" (delimit $cells ",")) -}} {{- end -}} {{- end -}} {{- $json := printf "[%s]" (delimit $rows ",") -}} {{- if lt (len $rows) 2 -}} {{- errorf "chart shortcode %s: needs a header line plus at least one data line" $id -}} {{- end -}}
