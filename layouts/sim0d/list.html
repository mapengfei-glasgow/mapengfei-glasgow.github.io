Model

Closed-loop systemic and pulmonary circulation (ambit modeltype: "syspul"), 18 unknowns: four chambers, four valves, an aortic root with characteristic impedance Z, systemic arteries/veins and pulmonary arteries/veins as RCL compartments. Each chamber is a time-varying elastance, \(V = p/E(t) + V_u\), \(E(t) = (E_{\max}-E_{\min})\,y(t) + E_{\min}\), with a cosine activation \(y(t) = \tfrac12\,[1-\cos(2\pi (t-t_0)/t_{\mathrm{act}})]\): atria \(t_0 = 0\), \(t_{\mathrm{act}} = 2t_{ed}\); ventricles \(t_0 = t_{ed}\), \(t_{\mathrm{act}} = 1.8\,(t_{es}-t_{ed})\). Valves are pressure-dependent resistances, \(R = R_{\min}\) when open and \(R_{\max}\) when closed.

Time integration is ambit's one-step-θ scheme on \(\mathbf r = \big(\mathbf d\mathbf f(\mathbf x_{n+1}) - \mathbf d\mathbf f(\mathbf x_n)\big)/\Delta t + \theta\,\mathbf f(\mathbf x_{n+1}) + (1-\theta)\,\mathbf f(\mathbf x_n) = \mathbf 0\), solved by Newton's method; the first step uses backward Euler (θ = 1). Periodicity is checked at the end of every cycle with the relative change of the state vector. Inputs use ambit's kg–mm–s units (pressure in kPa = kg/(mm·s²), volume in mm³); results are shown in mmHg and mL.
